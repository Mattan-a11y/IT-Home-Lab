# Visa labbet för arbetsgivare

## Kort beskrivning för portföljen
Jag bygger en egen isolerad, virtualiserad IT-supportmiljö i VMware för att omsätta Windows Server, Active Directory, nätverk och Windows-klientsupport till praktiska övningar. Projektet dokumenteras öppet med konfigurationssteg, felsökning och simulerade supportärenden. Befintlig första del omfattar Windows Server 2025, statisk IP och domänkontrollant för `lab.local`; resterande moment dokumenteras efter faktisk verifiering.

- Dokumenterat tekniska arbetsmoment och lösningar med skärmbilder i GitHub.
