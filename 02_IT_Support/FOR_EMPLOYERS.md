# Min IT-portfölj — text till CV och LinkedIn

## Projekt: IT Home Lab

**Mitt projekt**

Jag har byggt en virtuell Windows Server-miljö i VMware och konfigurerat Active Directory Domain Services med en egen domänkontrollant. Under installationen stötte jag på ett fel i förutsättningskontrollen, identifierade orsaken och slutförde konfigurationen. Jag dokumenterade det med skärmbilder på GitHub.

I tidigare Active Directory-övningar installerade jag också Windows 11 i VMware och arbetade med DNS, DHCP och klienttester. Det är praktiska moment jag genomfört, men jag har ännu inte lagt in samma detaljnivå av dokumentation för dem i detta repository.

**Tekniker jag har arbetat med:** VMware, Windows Server 2025, Active Directory, Windows 11, DNS och DHCP.

**GitHub:** https://github.com/Mattan-a11y/IT-Home-Lab
