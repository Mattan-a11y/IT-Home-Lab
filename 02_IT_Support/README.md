# Mina tidigare övningar — Windows 11, DNS, DHCP och klienttester

Utöver min dokumenterade installation av Windows Server 2025 och Active Directory har jag **tidigare installerat Windows 11 i VMware och arbetat med DNS, DHCP och klienttestning** under mina Active Directory-övningar.

Det här är en sammanfattning av **arbete jag redan gjort**, inte en installationsguide eller en lista över uppgifter som andra ska genomföra.

## Windows 11 i VMware

Jag installerade Windows 11 som en virtuell klient i samband med mina tidigare Active Directory-övningar. På så sätt fick jag praktisk erfarenhet av både server- och klientsidan av en Windows-miljö.

Jag har ännu inte lagt in skärmbilder från just Windows 11-övningen i detta repository.

## DNS och DHCP

Jag arbetade också med DNS och DHCP samt testade klientfunktionalitet i samband med mina övningar. Det har gett mig erfarenhet av de nätverkstjänster som används för namnuppslagning och IP-adressering.

Jag har inte kvar detaljerad dokumentation här över varje konfiguration eller varje testresultat. Därför beskriver jag inte något specifikt DNS- eller DHCP-fel som om jag säkert vet att jag löste det.

## Active Directory och felsökning

Ett moment jag **har dokumenterat** är när jag installerade Windows Server 2025, konfigurerade en domänkontrollant och löste felet med ett administratörskonto utan lösenord under förutsättningskontrollen.

## Vad denna erfarenhet innebär

Jag har övat på att arbeta med virtuella Windows-miljöer, grundläggande nätverkstjänster och Active Directory. Det är relevant för junior IT-support, särskilt när jag behöver förstå skillnaden mellan problem på klienten och problem med en tjänst på servern.

**Detta är mitt eget labbarbete – inte sex avslutade kundärenden och inte tidigare anställning på helpdesk.**
